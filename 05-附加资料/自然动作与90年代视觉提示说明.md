# 图片修订提示与执行方式

工具：内置image_gen图片生成/编辑；每个全身与近景分别生成，近景不从全身裁切。以原有六套全身及对应人像作身份、服装、地点参考。

共同提示：同一位成年女性，锁定脸型、发色、发型、服装及配饰、地点、时段；表情和姿态来自街头真实小事；不看镜头，不展示性摆姿。近景胸部以上、脸占画面约一半，新机位与自然状态。细腻90年代纽约都会杂志彩色负片质感，暖中间调/肤色、冷灰阴影、克制高光溢出、细颗粒与丰富黑色；保留玫红和钴蓝真实独立色相。不加文字、水印、AI标识。黑/灰西装为平整羊毛斜纹，不变成浮雕或花纹面料。

01：带咖啡走到街角/等红灯，风吹头发，看路况或听身边人说话。
02：取花后向花店工作人员道别，抱白色马蹄莲，自然提黑色人脸包。
03：下黄色出租车/和司机交流，象牙白服装与大黑平檐帽。
04：抱花和文件夹过街、听旁边人说话，灰色西装与四条纹百褶裙。
05：买面包走出店门/看前方车流，钴蓝大衣和红心包。
06：走向餐厅，向同行者回头回应；黑白花裙与披风。左手拿自己的手包，另一只手自然放松或扶自己的披风，不与另一人牵手。近景不强行展示手。

封面：4:3蓝大衣买面包的街角，16:9玫红裙咖啡过街，9:16黑帽象牙白下车；3:4复用新版第一张。不同画幅分别构图。

账号版：仅在最终无字母版上以原分辨率叠加优雅白色半透明The Style Switch、平台图形与已确认账号；不改写摄影画面、不加文字底板。摄影修订与滤镜由图像工具完成。

最新表情要求：不要奇怪表情。逐张检查嘴角、眼神和眉眼；保留放松浅笑、自然笑容或专注状态。第五组近景单独修正嘴角为自然、轻微、闭口的浅笑，避免抿嘴、歪嘴、挑眉和刻意表情，其余身份、造型、构图和色调不变。
